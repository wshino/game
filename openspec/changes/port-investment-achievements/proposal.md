# 提案: 港への投資システムと実績システム

## 概要

お金を使う目標を追加し、ゲームに長期的な目的を提供する。港への投資と実績（称号）システムを導入する。

## 現状の問題点

現在のゲームには以下の問題がある：

1. **お金の使い道が限定的**
   - 船のアップグレード（最大50,000G）が唯一の大きな出費
   - それを達成すると、お金が無限に増えるだけの作業ゲーになる
   - 長期的な目標がない

2. **港との関わりが浅い**
   - 港は単なる取引場所でしかない
   - 港ごとの特別な恩恵や愛着が生まれない

3. **達成感の不足**
   - 明確な目標や称号がない
   - プレイヤーの進捗を示す指標がない

## 提案する解決策

### 1. 港への投資システム 🏛️

各港に施設を建設して、長期的な恩恵を得る仕組み。

#### 施設の種類

**倉庫（Warehouse）**
- **コスト**: 5,000G（レベル1）、10,000G（レベル2）、20,000G（レベル3）
- **効果**: その港で商品を保管できる（レベル×50個）
- **用途**: 港在庫が不足している時の補完、価格が良い時まで待つ

**商館（Trading Post）**
- **コスト**: 10,000G（レベル1）、20,000G（レベル2）
- **効果**: その港での取引価格が優遇される（レベル×5%）
- **用途**: 長期的な利益向上

**造船所（Shipyard）**
- **コスト**: 15,000G
- **効果**: その港で船の修理・メンテナンスが可能（将来の拡張用）
- **用途**: 将来的な船のダメージシステムに対応

**市場拡張（Market Expansion）**
- **コスト**: 8,000G（レベル1）、16,000G（レベル2）
- **効果**: 港の在庫上限と回復速度を向上（+25%）
- **用途**: より多くの商品を購入可能にする

#### 港の名声システム

- 各港への総投資額に応じて名声レベルが上がる
- 名声レベル:
  - **無名（0G）**: 普通の商人
  - **知人（10,000G）**: 港で顔を知られる
  - **友人（30,000G）**: 港から信頼される
  - **名士（60,000G）**: 港の重要人物
  - **支配者（100,000G）**: 港を実質的に支配

### 2. 実績・称号システム 🏆

金額や行動ベースの目標を追加。

#### 財産ベースの称号

- **見習い商人（0G）**: ゲーム開始時
- **商人（10,000G達成）**: まともな資産を持つ
- **大商人（50,000G達成）**: 船をアップグレード完了
- **豪商（100,000G達成）**: 大きな富を築く
- **貿易王（500,000G達成）**: 膨大な富
- **海洋覇者（1,000,000G達成）**: 伝説の商人

#### 行動ベースの実績

- **世界一周（全7港を訪問）**: 初回ボーナス+1,000G
- **香辛料王（香辛料を累計500個取引）**: 香辛料取引+3%
- **貿易マスター（累計100回の航海）**: 補給費用-10%
- **投資家（全港に少なくとも1つの施設）**: 全港での取引+2%
- **港の支配者（1つの港で名声レベル最大）**: その港での特別ボーナス

#### 称号の効果

- 称号に応じて特別なボーナスを付与
- UI上で称号を表示（ステータスバーに追加）
- 達成時に特別なアニメーション

## 期待される効果

1. **長期的な目標**: 数十万〜百万ゴールドの目標ができる
2. **お金の使い道**: 船以外の有意義な支出先
3. **戦略性の向上**: どの港に投資するか、どの施設を優先するか
4. **港への愛着**: 特定の港を重視する戦略が生まれる
5. **やり込み要素**: 全港制覇、全実績達成などの目標

## ゲームバランスへの影響

### 投資のROI（投資回収期間）

**例: 商館レベル1（10,000G）をカリカットに建設**
- 効果: 取引価格5%優遇
- 香辛料の往復利益: 150G/個 → 158G/個（+8G）
- 100個取引で+800G
- ROI: 約13回の取引で回収（現実的）

**例: 倉庫レベル1（5,000G）**
- 効果: 50個の保管スペース
- 用途: 価格変動待ち、在庫不足時の補完
- ROI: 間接的（柔軟性の向上）

### 実績ボーナスのバランス

- ボーナスは控えめ（2-10%）
- 達成に時間がかかる目標に大きなボーナス
- ゲームを壊さない範囲で恩恵を提供

## リスクと対策

### リスク1: ゲームバランスの崩壊

- **対策**: 施設のコストとボーナスを慎重に調整
- **対策**: 初期実装後にバランステストを実施

### リスク2: UI が複雑になる

- **対策**: シンプルなUIデザイン
- **対策**: 段階的な情報開示（初心者には見せない）

### リスク3: セーブデータの肥大化

- **対策**: 効率的なデータ構造
- **対策**: 不要なデータは保存しない

### リスク4: 実装の複雑さ

- **対策**: 段階的な実装（Phase 1: 投資、Phase 2: 実績）
- **対策**: テストしながら進める

## 実装の優先順位

### Phase 1: 基本的な投資システム（高優先）
- 倉庫と商館のみ
- 1レベルのみ
- シンプルなUI

### Phase 2: 実績システム（中優先）
- 財産ベースの称号
- 基本的な行動実績
- 称号表示

### Phase 3: 拡張（低優先）
- 施設のレベルアップ
- 複雑な実績
- アニメーション強化
